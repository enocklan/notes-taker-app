# 📝 Notes Taker App

A simple and responsive **Notes Taker App** built with **HTML, CSS, and JavaScript**. The application allows users to create, view, edit, and delete notes directly from the browser.

## 🚀 Features

* ✍️ Create new notes
* 📖 View saved notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 💾 Save notes using browser local storage
* 📱 Responsive design
* 🎨 Clean and simple user interface
* ⚡ Fast and lightweight — no backend required

## 🛠️ Technologies Used

* **HTML5** – Application structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and note management
* **Local Storage** – Persistent storage of notes in the browser

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/enocklan/notes-taker-app.git
```

### 2. Navigate to the project

```bash
cd notes-taker-app
```

### 3. Open the application

You can simply open:

```text
index.html
```

in your web browser.

Alternatively, you can use **VS Code Live Server** to run the project locally.

## 🎯 How to Use

1. Open the application in your browser.
2. Enter your note in the provided input area.
3. Save the note.
4. Select a saved note to view or edit it.
5. Delete a note when it is no longer needed.

Your notes are stored locally in the browser, so they can remain available after refreshing the page.
